## Phase 1: CallerPort (branch p4/phase-1-caller-port)

`apps/server/src/caller`: `createCaller({ config: loadCallerConfig(), runtime, onResult })` returns `{ port, registerWebhook(app), start, stop }`. CALLER_MODE=fake (default) is FakeCaller; real is ElevenLabsCaller over Twilio. book() dials through ElevenLabs with dynamic variables (window -30/+60 min), 20 s ring timeout; no answer, voicemail, or full tries the backup venue once; exactly one CallResult per booking reaches onResult.
